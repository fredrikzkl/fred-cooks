---
title: Kikertkarri med spinat
status: certified 
tags: ["Gryte", "Barn", "Vegan"]
ingredients:
  - { name: gulløk,                  amount: 1 stor, section: Grønnsaker }
  - { name: hvitløk,                 amount: 5 fed, section: Grønnsaker }
  - { name: ingefær (fersk),         amount: 2.5 cm, section: Grønnsaker }
  - { name: ferske tomater (cherry), amount: 3 stk, section: Grønnsaker }
  - { name: spinat,                  amount: 5 dl, section: Grønnsaker }
  - { name: tomatpuré,               amount: 1 boks }
  - { name: kikerter,                amount: 900g }
  - { name: olivenolje,              amount: etter behov }
  - { name: grønnsakskraft,          amount: 1–2 dl (1 buljong) }
  - { name: kokosnøttmelk,           amount: 6 dl }
  - { name: curry powder,            amount: 2 ss, section: Krydder }
  - { name: allehånde,               amount: ½ tsk, section: Krydder }
  - { name: malt ingefær,            amount: ½ tsk, section: Krydder }
  - { name: garam masala,            amount: ½ tsk, section: Krydder }
  - { name: gurkemeie,               amount: ¼ tsk, section: Krydder }
  - { name: chiliflak,               amount: ⅛ tsk, section: Krydder }
  - { name: timian (helst fersk),    amount: 4 stilker, section: Krydder }
sides:
  - "rødløk"
servings: 6
prep_time: 15m
total_time: 45m
updated: 26.05.2026
---

1. Del gulløken i biter. Finhakk hvitløk og ingefær. Skjær tomatene i større chunks.
2. Varm olivenolje i en gryte på medium varme og stek gulløken til den er myk.
3. Tilsett hvitløk, ingefær og timian.
4. Legg i de hakkede tomatene og knus dem litt så saften kommer ut. La det redusere et par minutter.
5. Tilsett alle krydderne og stek dem kort for å aktivere smaken.
6. Bland inn tomatpuréen og la den karamellisere seg.
7. Hell på kokosnøttmelk og grønnsakskraft. Smekk i kikertene — husk å sile av væsken fra boksen først.
8. La det småkoke i 20–25 minutter til det er kremet.
9. Rør inn spinaten et par minutter før servering.
10. Topp med rødløk og server.
