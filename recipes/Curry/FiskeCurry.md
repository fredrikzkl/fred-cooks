---
title: Fiske Curry (Torsk) 🥘🐟
tags: ["Gryte", "Fisk"]
ingredients:
  - { name: gulløk,                        amount: 1 stor, section: Grønnsaker }
  - { name: ingefær (fersk),               amount: 1 tommel, section: Grønnsaker }
  - { name: hvitløk,                       amount: 6–8 fedd, section: Grønnsaker }
  - { name: potet,                         amount: 300g, section: Grønnsaker }
  - { name: kålrot,                        amount: 300g, section: Grønnsaker }
  - { name: torsk (eller annen hvit fisk), amount: 400g, section: Fisk }
  - { name: kokosmelk,                     amount: 660 ml }
  - { name: gurkemeie,                     amount: 1 tsk, section: Krydder }
  - { name: grønn thai curry paste,        amount: 3 tsk, section: Krydder }
  - { name: salt og pepper,                amount: smak til, section: Krydder }
  - { name: sitron,                        amount: smak til, section: Krydder }
sides:
  - spinat
servings: 4
prep_time: 20m
total_time: 50m
status: certified 
updated: 26.05.2026
---

1. Skjær gulløken i biter. Finhakk ingefær og hvitløk. Skjær potet og kålrot i biter (kålroten litt mindre enn potetene). Skjær torsken i biter.
2. Sauter gulløken i litt olje.
3. Tilsett hvitløk og ingefær på medium varme.
4. Tilsett gurkemeie og grønn thai curry paste, og la smakene komme frem.
5. Bland inn kokosmelken.
6. Tilsett potet og kålrot. La det koke i 20 minutter på lav varme — kokosmelk brenner seg lett i bunnen, så følg med.
7. Tilsett fisken og la den koke i 5 minutter.
8. Smak til med sitron, salt og pepper.
