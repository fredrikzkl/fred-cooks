---
title: Superenkel Fiskegrateng
tags: ["Middag", "Fisk"]
ingredients:
  - { name: torsk (rå),         amount: 400g }
  - { name: makaroni (ukokt),   amount: 125g }
  - { name: vårløk,             amount: 3 }
  - { name: egg,                amount: 3 }
  - { name: smør,               amount: 2–3 ss, section: Saus }
  - { name: hvetemel,           amount: 2–3 ss, section: Saus }
  - { name: melk,               amount: 5 dl, section: Saus }
  - { name: muskat,             amount: 1 klype, section: Saus }
  - { name: salt og pepper,     amount: smak til, section: Saus }
  - { name: knekkebrød (knust), amount: 2, section: Topping }
sides:
  - kokte poteter
  - gulrot
  - smeltet smør
servings: 4
prep_time: 15m
total_time: 1h
status: brewing
updated: 27.05.2026
---

1. Lag en hvit saus: smelt smøret og rør inn hvetemelet. Spe med melken litt og litt, rør kraftig og la det koke opp mellom hver påfylling for å unngå klumper. Krydre med muskat, salt og pepper. La det småkoke i 5 minutter.
2. Bland i makaronien og sett til side så det får avkjøles litt.
3. Skjær torsken i terninger og vårløken i skiver.
4. Visp inn ett og ett egg i den hvite sausen. Vend så inn torsk og vårløk.
5. Hell blandingen over i en ildfast form og strø over knust knekkebrød.
6. Stek midt i ovnen på 225° i ca. 45 minutter.
