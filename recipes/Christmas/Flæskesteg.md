---
title: Flæskesteg
tags: ["Middag", "Jul"]
ingredients:
  - { name: ribbe,                   amount: 1 stykke (ca. 2kg), section: Kjøtt }
  - { name: kokende vann,            amount: nok til å dekke svoren, section: Annet }
  - { name: salt,                    amount: "ca. 1 % av kjøttets vekt", section: Krydder }
  - { name: hel pepper,              amount: smak til, section: Krydder }
  - { name: laurbærblad (valgfritt), amount: noen, section: Krydder }
  - { name: timian (valgfritt),      amount: noen stilker, section: Krydder }
  - { name: nellik (julestemning),   amount: noen, section: Krydder }
sides:
  - rødkål
  - poteter
servings: 6
prep_time: 15m
total_time: 2h 30m
status: brewing
updated: 27.05.2026
---

1. Salt svoren — ca. 1 % av kjøttets vekt.
2. Legg ribba opp ned i en ildfast form og hell kokende vann i formen til svoren er dekket.
3. Sett i ovnen i 20 minutter på 200° varmluft.
4. Ta ut, snu steken, og kutt i svoren. Legg sølvpapir under steken for å gjøre den mest mulig vannrett, og legg krydderne under (hel pepper, laurbærblad, timian, nellik).
5. Sett tilbake i ovnen i 1,5 timer på 200° varmluft.
6. La steken hvile i 20 minutter før servering.

**Tips:** Tynnere kutt i svoren = sprøere svor. Hvis du har tid, salt svoren noen timer eller en natt i forveien for ekstra sprø svor.
