title: Freds Chilli 🌶️

  - { name: rød paprika,        amount: 1 (eller 2–3 chilier for ekstra sterk), section: Grønnsaker }
  - { name: hvitløksfedd,       amount: 3–5, section: Grønnsaker }
  - { name: kjøttdeig,          amount: 800g (helst 50/50 svin/storfe) }

  - { name: hakkede tomater,    amount: 400g }
  - { name: passata,            amount: 700–800g }

  - { name: pintobønner,        amount: 450g }

  - { name: salt,               amount: 2 tsk, section: Krydder }
  - { name: chili powder,       amount: 4 tsk, section: Krydder }
  - { name: ancho chile powder, amount: 2 tsk, section: Krydder }
  - { name: oregano,            amount: 4 tsk tørket, section: Krydder }
  - { name: cayennepepper,      amount: smak til, section: Krydder }

1. Del gulløken og paprikaen i biter. Finhakk hvitløken (ikke pulver, men veldig små biter).
2. Bland krydderblandingen (svart pepper, salt, chili powder, ancho chile powder, oregano) i en liten skål.
3. Varm olivenolje i en stor gryte på 7/9 varme. Sauter løken i 2–3 minutter, deretter paprikaen i 2–3 minutter, og til slutt hvitløken (må ikke brennes). Sauter til løken og paprikaen er myke.
4. Skru opp til 8/9 varme og tilsett kjøttdeigen. Stek til den er ca. 75% ferdig (fortsatt litt rødt igjen).
5. Senk varmen til 6/9. Bland inn tomatpuréen og karamelliser den så mye som mulig.
6. Tilsett krydderblandingen og stek krydderet kort for å aktivere smaken.
7. Hell oppi de hakkede tomatene og passataen.
8. Reduser varmen til 4/9, sett på lokk og la det småkoke i minimum 1 time, helst 3 eller mer.
9. 20 minutter før servering: bland inn bønnene. Hell av vannet fra kidneybønnene; pintobønnene tilsettes med all væsken.
10. Smak til. Tilsett cayennepepper hvis den ikke er sterk nok, eller litt soyasaus hvis den ikke er salt nok.
