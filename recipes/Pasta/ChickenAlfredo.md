---
title: Chicken Alfredo (Blomkål edition)
tags: ["Middag", "Snikgrønt"]
ingredients:
  - { name: kyllingfilet (bryst/lår), amount: 450g }
  - { name: tagliatelle,              amount: 500g }
  - { name: squash (zucchini),        amount: 1 }
  - { name: blomkål,                  amount: 1 hel, section: Saus }
  - { name: hvitløk,                  amount: 3–5 fedd, section: Saus }
  - { name: parmesan,                 amount: 50g, section: Saus }
  - { name: melk,                     amount: 1 dl, section: Saus }
  - { name: smør,                     amount: 30g, section: Saus }
  - { name: salt og pepper,           amount: smak til, section: Saus }
servings: 4
prep_time: 15m
total_time: 45m
status: brewing
updated: 27.05.2026
---

1. Del kyllingfileten i to og salt og pepre godt.
2. Kok opp to gryter med vann — god mengde salt i begge.
3. Kok blomkålen i den ene gryta i ca. 9 minutter. Kok pastaen etter pakkens anvisning i den andre.
4. Stek kyllingen i panne, ca. 3 minutter på hver side. La den hvile i 5 minutter etter steking.
5. Ha blomkål, parmesan, hvitløk, melk, smør, salt og pepper i en blender. Kjør glatt.
6. Skjær squashen i biter og stek i samme panne som kyllingen.
7. Vend pastaen i blomkålsausen og server med kylling og squash på toppen.

**Tips:** 5 hvitløksfedd gir veldig sterk hvitløkssmak — start med 3 om du er usikker.
