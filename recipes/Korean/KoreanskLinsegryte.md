---
title: Koreansk Linsegryte
tags: ["Gryte", "Vegan"]
ingredients:
  - { name: røde eller grønne linser,                   amount: 2.5 dl, section: Linser }
  - { name: løk (hakket),                               amount: 2, section: Linser }
  - { name: hvitløk (hakket),                           amount: 4 fedd, section: Linser }
  - { name: vann,                                       amount: 5 dl, section: Saus }
  - { name: soyasaus,                                   amount: 0.5 dl, section: Saus }
  - { name: fersk ingefær (revet),                      amount: 1 tommel, section: Saus }
  - { name: sesamolje,                                  amount: 1 ts, section: Saus }
  - { name: brunt sukker,                               amount: 2 store ss, section: Saus }
  - { name: koreanske røde chiliflakes (eller vanlige), amount: 1 stor ts, section: Saus }
  - { name: vårløk (hakket),                            amount: smak til, section: Topping }
  - { name: sesamfrø,                                   amount: et lett dryss, section: Topping }
sides:
  - ris
  - nudler
servings: 4
prep_time: 15m
total_time: 45m
status: certified
updated: 26.05.2026
---

1. Bland alle sausingrediensene i en bolle og sett til side.
2. Stek løken i litt olje i en gryte til den er litt myk.
3. Tilsett hvitløken og stek et minutt til — pass på at den ikke brenner seg.
4. Hell oppi linsene og rør godt sammen.
5. Hell på sausen, rør og kok opp.
6. Skru ned til middels varme, legg på lokk og la det småkoke i 20–40 minutter. Spe med litt vann om det blir tørt.
7. Server over ris eller nudler, med hakket vårløk og et lett dryss sesamfrø på toppen.

**Tips:** Sesamoljen kan sløyfes, men gir veldig god smak. Juster chiliflakene etter ønsket sterkhet — mer om du liker sterk mat, mindre om du er sart for sterkt.
